# Todo-list App created in a course: Build Your First App with AI

## Features:
Allows users to:
- Add new task with due date (optional)
- Group tasks up with a single overhead name with task listed below it
- Remove task(s)
- Undo last action
- Bulk remove
- Sort tasks: Due date, in order added
- Clear all tasks
- Check tasks as complete
- Check current time in clock
Also includes stylistic elements:
- Rocket League theme, with imported logo
- Cars created with shapes available
- "Coding" background with actual code hidden within it that is used
- Rocket League ranks

## How it works:

- Opens in its own browser page (at least I think), allowing user to perform tasks
- Type in task, add due date if wanted, hit enter
- Add more tasks if wanted
